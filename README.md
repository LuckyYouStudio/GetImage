# LuckyYou 图像工作台

面向中转站用户的图片生成前端：打开网页、填自己的 API Key、开始出图。单个 `index.html`，无框架、无构建、无后端，部署到中转站域名下即可。

- **文生图 / 图生图**：`gpt-image-2`，图生图支持拖入、粘贴、多张参考图
- **多张并行**：接口不支持一次多张，页面用并发请求实现（并发数可调）
- **历史记录**：所有结果自动存入浏览器 IndexedDB，可回看、复用提示词、当参考图、下载、删除
- **风格标签**：一键给提示词追加"电影感光线 / 水彩插画 / 3D 渲染 …"
- **失败自动诊断**：出错时自动核对服务端模型列表，区分"模型名不对"和"权限/上游故障"
- 浅色 / 深色主题，移动端可用

```
GetImage/
├─ index.html   全部前端代码。部署只需要这一个文件
├─ DEPLOY.md    ← 部署到中转站域名下的步骤（Caddy / Nginx 配置）
├─ API.md       接口协议实测记录，给自动化对接用
├─ proxy.py     本地运行用的启动器（部署后不需要）
├─ 启动.bat     Windows 本地运行
├─ start.bat    同上（ASCII 文件名）
└─ start.sh     macOS / Linux 本地运行
```

## 部署（正式用法）

把 `index.html` 放到 `img.the5288.com` 下任意路径，例如 `https://img.the5288.com/studio/`。页面与接口同源，没有跨域问题，不需要任何服务端改动。

具体步骤和 Caddy / Nginx 配置见 **[DEPLOY.md](DEPLOY.md)**。品牌名、产品名、领 Key 的链接都在 `index.html` 开头的 `BRAND` 对象里改。

## 本地运行（预览 / 个人使用）

> ⚠️ 不要直接双击 `index.html`——`file://` 页面会被浏览器的 CORS 策略拦截，页面会提示你改用下面的方式。

**Windows：** 双击 `启动.bat`　**macOS / Linux：** `./start.sh`　**任意平台：** `python proxy.py`

会在 `127.0.0.1:8788` 起一个本地服务（同时提供页面 + 转发接口），浏览器自动打开。需要 Python 3.7+，无第三方依赖。8788 被占用会自动顺延。

## 使用

1. 首次打开会弹出设置，填 **API Key**（只存在你自己的浏览器里）
2. 写提示词，可点风格标签追加，`Ctrl / ⌘ + Enter` 生成
3. **图生图**：切到「图生图」标签，拖入 / 粘贴 / 选择参考图，再写要改什么
4. 结果卡片：下载、当参考图继续改、按同样提示词再来一张；点图放大
5. 顶栏「历史」查看全部过往结果

## 接口行为（实测要点）

详见 [API.md](API.md)。对使用者最相关的几条：

| 现象 | 说明 |
|---|---|
| 只有 `gpt-image-2` 能出图 | `gpt-image-1` / `gpt-image-1.5` 在列表里但调用返回 502 |
| 单张 40–60 秒 | 正常，页面卡片上有计时 |
| `n` 参数无效 | 服务端静默忽略，页面用并发多请求实现多张 |
| `size` 可能不被遵守 | 卡片上显示的是返回图的**真实**尺寸，不是请求值 |
| 502 `Upstream access forbidden` | 请求来源被拒。本地模式下是代理 UA 问题（已处理）；正式部署不会遇到 |

## 数据与隐私

- API Key：`localStorage`，明文，仅本机浏览器；除接口本身外不发给任何地方
- 历史图片：`IndexedDB`，默认最多 120 张，超出淘汰最旧的；「设置 → 清除全部本地数据」一键清空
- 页面无后端、无埋点、无外部资源加载

## 已知限制

- 图生图多张参考图（`image[]`）、非方形尺寸、`quality` / `background` / `output_format` 是否真正生效，均未逐一实测（每次验证要真实消耗一次生成）
- `/v1/images/variations` 服务端不支持（404）
- 历史存在浏览器里：换浏览器、清站点数据、无痕窗口都会丢
